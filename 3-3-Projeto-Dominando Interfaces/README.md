# 🚀 Projeto Java — Cálculo de Áreas de Figuras Geométricas

Projeto desenvolvido durante meus estudos de Java, com foco em Interfaces, Abstração e Polimorfismo.

---

## 📐 Cálculo de Áreas de Figuras Geométricas

> [!TIP]
> **Descrição**
>
> Aplicação desenvolvida em Java que permite calcular a área de diferentes figuras geométricas: quadrado, retângulo e círculo.
>
> O programa apresenta um menu interativo, recebe as dimensões informadas pelo usuário e retorna o resultado do cálculo.

> [!TIP]
> **Objetivo**
>
> Praticar os conceitos de programação orientada a objetos, utilizando interfaces, implementação de métodos, records e polimorfismo.
>
> Cada figura geométrica possui sua própria implementação do método `getArea()`, responsável por calcular sua respectiva área.

> [!TIP]
> **Tecnologias e Conceitos**
>
> - Java
> - IntelliJ IDEA
> - Interface (`interface`)
> - Records (`record`)
> - Polimorfismo
> - Sobrescrita de métodos (`@Override`)
> - Scanner para entrada de dados
> - Estruturas condicionais e repetição (`if`, `else if`, `while`)

---

> [!IMPORTANT]
> **Estrutura do Projeto**
>
> - `GeometricForm.java` — Interface que define o método `getArea()`.
> - `Square.java` — Representa o quadrado e calcula sua área.
> - `Rectangle.java` — Representa o retângulo e calcula sua área.
> - `Circle.java` — Representa o círculo e calcula sua área.
> - `Main.java` — Controla o menu, recebe as dimensões e apresenta os resultados.

> [!IMPORTANT]
> **Resultados e Aprendizados**
>
> Desenvolvimento de uma aplicação com diferentes figuras geométricas, utilizando uma interface comum para padronizar os cálculos.
>
> O projeto permitiu praticar a implementação de interfaces, o uso de records e a aplicação do polimorfismo, além de trabalhar com entrada de dados e organização de classes em Java.
